# 年会費決済アプリ — 要件一覧（ラフ）

## 1. 概要

卒業生向けの年会費（3,000円 / 1,000円）を、Square タッチ決済で徴収するための Android アプリ。

## 2. 前提条件

| 項目 | 内容 |
|------|------|
| 決済プラットフォーム | Square（Tap to Pay on Android） |
| Square アカウント | 作成済み |
| 決済デバイス | Square Reader（Bluetooth 接続）+ Android 端末 |
| Square 商品 | 事前登録済み（3,000円商品 / 1,000円商品） |
| アプリ形態 | Android ネイティブアプリ |
| 参考アプリ | [Square POSレジアプリ](https://play.google.com/store/apps/details?id=com.squareup&hl=ja) |

## 3. 機能要件

### 3.1 入力画面

| # | 項目 | 詳細 |
|---|------|------|
| F-01 | 卒業期入力 | 卒業期をドロップダウンから選択できる（第50期〜第N期）。N は `当年 - 1902` で自動算出（2026年 = 第124期）。デフォルトは最新期を選択状態にする |
| F-02 | フルネーム入力 | 氏名をフリーテキストで入力できる |
| F-03 | 支払金額選択 | 3,000円 / 1,000円 を選択できる |
| F-04 | 支払方法選択 | 以下から選択できる: クレジットカード / 交通系IC（Suica 等） / iD / QUICPay |
| F-05 | 決済開始ボタン | 入力内容を確認し、Square 決済フローを開始する |

### 3.2 デバイス接続

| # | 項目 | 詳細 |
|---|------|------|
| F-06 | Bluetooth 接続 | Square Reader と Android 端末を Bluetooth でペアリング・接続する |
| F-07 | 接続状態表示 | Square Reader の接続状態（接続中 / 未接続 / バッテリー残量）を画面上に表示する |
| F-08 | 再接続 | 接続が切れた場合に再接続を試みる |

### 3.3 決済フロー

| # | 項目 | 詳細 |
|---|------|------|
| F-09 | 決済リクエスト | 選択された金額・商品で Square SDK に決済リクエストを送る |
| F-10 | タッチ待ち画面 | ユーザーにカード／スマホを Square Reader にタッチするよう促す画面を表示する |
| F-11 | 決済結果表示 | 成功 / 失敗をユーザーに表示する |
| F-12 | 連続利用 | 決済完了後、次の利用者のために入力画面に戻れる |

## 4. 画面遷移（基本フロー）

```
入力画面
  ├─ 卒業期入力
  ├─ フルネーム入力
  ├─ 金額選択（3,000円 / 1,000円）
  └─ 支払方法選択
        │
        ▼
  [ 決済開始 ]
        │
        ▼
  タッチ待ち画面（Square SDK）
  ユーザーがカード or スマホをタッチ
        │
        ▼
  決済結果画面
  ├─ 成功 → 完了メッセージ → 入力画面に戻る
  └─ 失敗 → エラーメッセージ → リトライ or 入力画面に戻る
```

## 5. 非機能要件

| # | 項目 | 詳細 |
|---|------|------|
| NF-01 | 対応 OS | Android（Square Tap to Pay 対応バージョン） |
| NF-02 | ネットワーク | 決済時にインターネット接続が必要 |
| NF-03 | セキュリティ | カード情報はアプリ側で保持しない（Square SDK に委任） |
| NF-04 | 操作性 | 受付担当者が繰り返し操作するため、最小タップ数で決済完了できること |

## 6. スコープ外（今回やらないこと）

- レシート発行・メール送信
- 決済履歴の閲覧・管理（Square Dashboard で確認）
- ユーザー認証・ログイン機能
- 返金処理（Square Dashboard で対応）
