# 年会費決済アプリ — 画面ワイヤーフレーム

## 画面一覧

1. 入力画面（メイン）
2. 確認ダイアログ
3. タッチ待ち画面
4. 決済結果画面（成功）
5. 決済結果画面（失敗）

---

## 1. 入力画面（メイン）

```
┌─────────────────────────────────┐
│  年会費決済            🔵 Reader接続中  │
├─────────────────────────────────┤
│                                 │
│  卒業期                          │
│  ┌─────────────────────────┐    │
│  │ 第124期             ▼   │    │
│  └─────────────────────────┘    │
│                                 │
│  氏名                            │
│  ┌─────────────────────────┐    │
│  │                         │    │
│  └─────────────────────────┘    │
│                                 │
│  金額                            │
│  ┌────────────┐ ┌────────────┐  │
│  │  ¥3,000    │ │  ¥1,000    │  │
│  │  (選択中)   │ │            │  │
│  └────────────┘ └────────────┘  │
│                                 │
│  支払方法                         │
│  ┌──────┐┌──────┐┌────┐┌──────┐ │
│  │ カード ││交通系IC││ iD ││QUICPay│ │
│  │(選択中)││      ││    ││      │ │
│  └──────┘└──────┘└────┘└──────┘ │
│                                 │
│                                 │
│  ┌─────────────────────────┐    │
│  │       決済を開始する        │    │
│  └─────────────────────────┘    │
│                                 │
└─────────────────────────────────┘
```

**補足:**
- ヘッダー右上に Square Reader の接続状態を常時表示（🔵接続中 / 🔴未接続）
- 卒業期ドロップダウンのデフォルトは最新期（当年 - 1902）
- 金額・支払方法はボタングループで排他選択
- 氏名が未入力、または Reader 未接続の場合は「決済を開始する」ボタンを非活性にする

## 2. 確認ダイアログ

```
┌─────────────────────────────────┐
│                                 │
│  ┌───────────────────────────┐  │
│  │    以下の内容で決済します      │  │
│  │                           │  │
│  │  卒業期:  第120期           │  │
│  │  氏名:   山田 太郎          │  │
│  │  金額:   ¥3,000           │  │
│  │  支払方法: クレジットカード    │  │
│  │                           │  │
│  │  ┌─────────┐ ┌─────────┐  │  │
│  │  │ キャンセル │ │  OK     │  │  │
│  │  └─────────┘ └─────────┘  │  │
│  └───────────────────────────┘  │
│                                 │
└─────────────────────────────────┘
```

**補足:**
- 決済開始ボタン押下後、入力内容を確認するダイアログを表示
- OK → タッチ待ち画面へ遷移
- キャンセル → 入力画面に戻る

## 5. 決済結果画面（失敗）

```
┌─────────────────────────────────┐
│                                 │
│                                 │
│                                 │
│            ❌                   │
│                                 │
│        決済に失敗しました          │
│                                 │
│  エラー: カードが読み取れません      │
│  でした                          │
│                                 │
│                                 │
│  ┌─────────────────────────┐    │
│  │       もう一度試す          │    │
│  └─────────────────────────┘    │
│  ┌─────────────────────────┐    │
│  │       入力画面に戻る        │    │
│  └─────────────────────────┘    │
│                                 │
└─────────────────────────────────┘
```

**補足:**
- 「もう一度試す」→ 同じ内容でタッチ待ち画面へ再遷移
- 「入力画面に戻る」→ 入力内容を保持したまま入力画面へ戻る

---

## 画面遷移図

```
入力画面 ──→ 確認ダイアログ ──→ タッチ待ち画面 ──→ 成功画面 ──→ 入力画面（クリア）
   ↑            │                    │               │
   │         キャンセル             キャンセル          │
   │            │                    │               │
   ←────────────┘                    │               │
   ←─────────────────────────────────┘               │
   ←──────────────────────────────────────────────────┘
                                     │
                                     ↓
                                 失敗画面
                                  │    │
                          リトライ │    │ 戻る
                                  ↓    ↓
                            タッチ待ち  入力画面
                                     （内容保持）
```
